# Budget Tracker

A client-side personal budget tracker built with **HTML, CSS, JavaScript and jQuery**.

Mini project for *Web Development Client-Side* (BSc in Computing, TU Dublin, 2025).

## Features

- Add income and expense transactions, with form validation
- Overview of current balance, total income and total expenses
- Transactions table with delete
- Analytics page: spending by category and expense vs income
- Data saved in the browser with `localStorage`, so no backend is needed
- Responsive layout: sidebar on desktop, bottom navigation bar on mobile

## Running

Open `index.html` in a browser. No build step is needed.

## Pages

| Page                  | Purpose                  |
|-----------------------|--------------------------|
| `index.html`          | Home / overview          |
| `transactions.html`   | List of transactions     |
| `addTransaction.html` | Add a transaction        |
| `analytics.html`      | Charts and statistics    |
